# 题目描述
Alice 和 Bob 决定观看一部共有 `n` 集的电视剧，剧集编号为 `1` 到 `n`。这部剧将在接下来的 `n` 天播出。由于他们住在不同城市，所以每天播出的剧集可能不同。

第 `i` 天，Alice 所在城市会播放第 `a_i` 集，Bob 所在城市会播放第 `b_i` 集。

他们计划选择一段连续的天数 `[L, R]` 来观看这部剧。最开始，两个人都没有看过任何剧集。在这段时间内的每一天 `i`，会发生如下事情：

- 如果 Alice 已经看过第 `1,2,...,a_i-1` 集，并且还没有看过第 `a_i` 集，**那么她会在第 `i` 天观看第 `a_i` 集； 否则，她这一天什么也不看；**
- Bob 同理，如果他已经看过第 `1,2,...,b_i-1` 集，并且还没看过第 `b_i` 集，**那么他会在第 `i` 天观看第 `b_i` 集；否则，他这一天什么也不看。**
>这里是一个非此即彼的状态，这对于题意的理解非常关键

为了避免聊天时互相剧透，Alice 和 Bob 想选择一段 `[L,R]`，使得这段时间内的每一天都满足下面两种情况之一：

- 他们在这一天观看的是同一集；
- 或者他们这一天都什么也不看。

请计算有多少个合法的区间 `[L,R]`。

# 解题思路
对于一个固定的左端点，我们关心的是：从哪一天开始两人会开始不同步，这里的不同步是指一个人会给另一个人泄露剧情。
如果最早不同步的日子是bad，那么 $L <= R <= bad$ 都是可以的。
问题转化为：
>对每个L，能够快速的求出第一个不同步的bad位置。

我们一共需要维护三个数组：
- da\[n] ,db\[n],dp\[n]
da对应了Alice第一次看到a_i集的位置
db对应了 Bob第一次看到b_i集的位置
**这里需要注意的一点是，因为我们要维护第一次看到，那么对于数组就需要从右向左的依次遍历**
dp\[i]对应，如果第i天Alice和Bob都播放同一集，并且题目能在这一天同步观看这一集，那么从第i天开始，最早发生不同步的日子是dp\[i]

## 那么我们要如何求dp\[i]呢？

假设当前是第i天，有a\[i] = b\[i]，说明这一天两人播放的是同一级。
这一集是第a\[i]集，那么下一次要看的就是t ( $t = a[i] + 1$ )集

- 情况一：下一集出现的时间不同( $da[t] != db[t]$)
	- 那么有一个人就会先看到这一集，那就会造成剧透
	- 所以这里的不同步位置就是 $min(da[t],db[t]$)
- 情况二：下一集出现的时间相同
	- 那么就可以同步后续第一次不同步位置，即( $dp[i] = dp[da[x]]$)

之后针对每一个i计算他的坏位置，\[i , bad-1]求和即可
